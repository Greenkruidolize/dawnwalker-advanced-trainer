# Documentation

## Overview
Advanced trainer for The Blood of Dawnwalker — local memory reader for single-player sessions.

## Categories
- Survival (God Mode, Infinite Health, Stamina, One-Hit Kill)
- Combat (No Cooldown, Instant Skill Charge, Damage Multiplier)
- Resources (Money, Skill Points, Crafting Materials, Consumables)
- Exploration (Teleport, Save Position, No Clip)
- Movement (Super Speed, Infinite Jump)
- Unlock (All Skills, All Equipment, Max Level)
- Utility (Game Speed, Toggle All)

## Config
Settings stored in `%APPDATA%\DawnwalkerAT\config.json`.
